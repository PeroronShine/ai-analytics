# AI Analytics Platform

**ИИ-агент для автоматического анализа данных и генерации аналитических отчётов.**

Приложение позволяет загрузить табличные данные (`CSV`, `Excel`) и задать вопрос нейросети о данных.

---

## Особенности реализации:
- LLM действует как автономный агент: понимает контекст, выполняет конкретные задачи.
- Реализована защита от prompt-injection (фильтрация запрещённых слов + жёсткий системный промпт).
- Интерфейс позволяет взаимодействовать с агентом через веб-форму.
