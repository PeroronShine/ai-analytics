# AI Analytics Platform

**ИИ-агент для автоматического анализа данных и генерации аналитических отчётов.**

Веб-приложение, которое позволяет загрузить табличные данные (`CSV`, `Excel`), автоматически построить визуализацию и получить текстовый анализ с помощью нейросети GigaChat через программный API.

---

## Возможности
- **Мультиформатная загрузка**: поддержка `.csv`, `.xlsx`, `.xls`
- **LLM-аналитика**: программный вызов GigaChat API для поиска паттернов, расчёта метрик и генерации рекомендаций
- **Интерактивная визуализация**: гистограммы и корреляционные матрицы на базе Plotly
- **Адаптивный UI**: интерфейс на Streamlit, работающий без локальной установки у конечного пользователя

---

## Стек технологий
| Компонент        | Технология              |
|------------------|-------------------------|
| Фронтенд/UI      | `streamlit`             |

## Установка и запуск локально

### 1. Требования
- Python 3.8+
- Актуальный `Authorization Key` от [GigaChat Developers](https://developers.sber.ru/services/api-gigachat)

### 2. Клонирование
```bash
git clone https://github.com/PeroronShine/ai-analytics.git
cd ai-analytics-platform
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск
```bash
python -m streamlit run app.py
```
Приложение откроется по адресу `http://localhost:8501`. Введите ваш API-ключ в боковой панели для активации нейросети.

## Деплой

Проект оптимизирован для бесплатного хостинга **Streamlit Cloud**.

1. Создайте аккаунт на [share.streamlit.io](https://share.streamlit.io) (войдите через GitHub)
2. Нажмите **New app**
3. Настройте параметры:
   - **Repository**: `ai-analytics`
   - **Branch**: `main`
   - **Main file path**: `app.py`
4. Нажмите **Deploy!**

Через 1–2 минуты приложение будет доступно по прямой ссылке. Никакой локальной установки не требуется.

## Безопасность и API
- API-ключ вводится пользователем через `type="password"` и не сохраняется на сервере
- Для обхода корпоративных прокси-сертификатов используется глобальное отключение SSL-верификации (`verify=False`)
- Запросы к API выполняются программно через `requests`
