# AI Analytics Platform

Приложение для автоматического анализа данных с использованием нейросети GigaChat (Сбер).

## Функционал
- Загрузка файлов форматов CSV и Excel.
- Автоматическая статистика и визуализация данных (графики, диаграммы).
- Генерация текста-анализа (инсайтов, паттернов, рекомендаций) через API нейросети.

## Технологии
- **Python**: Streamlit, Pandas, Plotly, Requests.
- **AI**: GigaChat API (SberBank).
- **Hosting**: Streamlit Cloud.

## Как запустить локально
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите приложение: `streamlit run app.py`
